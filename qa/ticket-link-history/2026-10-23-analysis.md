# Historiske billetlinkændringer: analyse 2026-10-23

Godkendt enkeltkørsel: inspect-source `ticket-link-history`, [run 39962461160](https://github.com/thomtorn-lab/edm/actions/runs/39962461160), commit `ef31ff3`. Rå rapport: `2026-10-23-report.json`, ordret fra jobloggen.

Kørslen læste kun: SELECT i én `BEGIN READ ONLY`-transaktion. Intet netværk, intet skrevet.

**Loggen indeholder ikke URL'er.** "Ændring" betyder nedenfor, at `ticketUrl` stod blandt de ændrede felter i en sync-række. Om ændringen var reel eller kosmetisk, kan loggen ikke vise.

## Admin-overstyringer
- Beskyttelsen virker: 872 sync-forsøg på 10 events blev blokeret. Flest på TAP1- og Klein-events, op til 161 pr. event.
- Kilderne foreslår altså vedvarende et andet link end det, admin har valgt. Om admin-linket stadig er det rigtige, kan loggen ikke vise.

## Kan ikke fastslås
- Hvilke URL'er der blev erstattet.
- Om en enkelt ændring var reel eller kosmetisk.
- Om events havde et link ved oprettelsen.
- Linkets oprindelse.
- Ændringer før 2026-08-15 eller uden om loggen.
